# Even or Odd Checker

A simple and interactive web application that checks whether a given number is Even or Odd.

## About the Project

This project is created using HTML, CSS, and JavaScript. Users can enter any number and check whether it is Even or Odd by clicking the Check button.

The result is displayed directly on the webpage.

## Features

- Check whether a number is Even or Odd.
- Accept user input.
- Display results on the webpage.
- Show a message when the input is empty.
- Simple and clean user interface.
- Responsive-friendly design.

## Technologies Used

- HTML5 – For creating the webpage structure.
- CSS3 – For styling and designing the interface.
- JavaScript – For checking Even or Odd numbers.

## How to Use

1. Open the project in your browser.
2. Enter a number in the input field.
3. Click the **Check** button.
4. The result will appear on the webpage.
